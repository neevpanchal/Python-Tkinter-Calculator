# Contributing to Python Tkinter Calculator

Thank you for considering contributing to the **Python Tkinter Calculator**! We welcome all contributions from the community.

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues tab](https://github.com/neevpanchal/Python-Tkinter-Calculator/issues) to ensure the bug hasn't already been reported.
- If not, use the **Bug Report** template to submit an issue with steps to reproduce.

### 2. Suggesting Enhancements
- Open an issue using the **Feature Request** template describing your proposed feature.

### 3. Submitting Pull Requests
1. **Fork** the repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/Python-Tkinter-Calculator.git
   cd Python-Tkinter-Calculator
   ```
3. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/awesome-feature
   ```
4. **Make your changes** and test thoroughly:
   ```bash
   python main.py
   python "Tkinter calculator.py"
   ```
5. **Commit your changes**:
   ```bash
   git commit -m "Add: awesome new feature"
   ```
6. **Push to your branch**:
   ```bash
   git push origin feature/awesome-feature
   ```
7. **Open a Pull Request** against the `main` branch.

## Code Style
- Follow [PEP 8](https://peps.python.org/pep-0008/) naming conventions and formatting guidelines.
- Add descriptive comments and docstrings.
- Ensure the application runs cleanly without console warnings.
